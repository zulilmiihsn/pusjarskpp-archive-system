## 3. Diagram Besar Untuk Excalidraw

Gambarkan 4 lane sejajar:

```text
Dokumen surat PDF/DOCX
-> pilih kegiatan
-> pilih sub-kegiatan
-> isi / ekstrak metadata
-> review user
-> output 1: file tersimpan di folder persuratan 2026
-> output 2: baris baru masuk spreadsheet daftar arsip
```

Kemudian pecah menjadi 4 lane di bawah ini.

```text

- Ket.
- Lokasi Simpan
```

Default / aturan:

```text

Kode rekap: PDP.07
Kode detail sering muncul: PDP.07.1, SDM.03.01, HM.03.1, PDP.03.5, atau kosong
Sub-kegiatan wajib: angkatan/kerjasama
Jenis dokumen umum: permohonan Latsar, kerja sama, balasan fasilitasi, pemanggilan peserta, ATK/sarpras, pembukaan, mentor, penguji/narasumber, habituasi, KRA, sertifikat, pengembalian peserta
```

## 9. Pertanyaan Untuk Validasi Client

```text
1. Apakah path daftar arsip dan folder penyimpanan ini sudah benar?
2. Apakah 4 kegiatan ini sudah menjadi menu utama app?
3. Apakah subfolder riil ini harus menjadi sub-menu app?
4. Untuk Latsar, apakah setiap angkatan wajib punya rekap berkas dan detail item?
5. Untuk Teknis, apakah Proposal/TOR tetap diproses sebagai persuratan?
6. Untuk Lain-lain, apakah subfolder SK Tim Kerja tetap dikeluarkan dari MVP?
7. Apakah kolom metadata spreadsheet ini sudah final?
8. Apakah app boleh mengisi metadata kosong seperti Kode Klasifikasi dengan rekomendasi, atau tetap dibiarkan kosong untuk user review?
```
