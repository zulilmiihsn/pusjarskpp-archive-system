# Client Validation Checklist

Gunakan checklist ini sebelum development penuh.

## Scope

- [ ] Benar bahwa tahap pertama hanya persuratan.
- [ ] Benar bahwa tahun fokus adalah 2026.
- [ ] Benar bahwa output berada di `1. Arsip Latbang`.
- [ ] Benar bahwa folder `4. Kegiatan Pelatihan dan Pengembangan` dipakai sebagai sumber/referensi kerja.
- [ ] Benar bahwa `Notulensi` tidak masuk scope MVP.
- [ ] Benar bahwa `SK/Surat Tugas` top-level tidak masuk scope MVP.

## Menu

- [ ] Empat menu utama sudah benar: Kepemimpinan, Latsar CPNS, Teknis, Lain-lain.
- [ ] Sub-menu Kepemimpinan sudah benar.
- [ ] Sub-menu Latsar CPNS sudah benar.
- [ ] Sub-menu Teknis sudah benar.
- [ ] Sub-menu Lain-lain sudah benar.
- [ ] Ada sub-kegiatan yang perlu ditambah/dihapus.

## Workflow

- [ ] User memilih kegiatan terlebih dahulu.
- [ ] User memilih sub-kegiatan/angkatan/batch.
- [ ] User upload atau pilih surat.
- [ ] App membaca metadata.
- [ ] User review sebelum file final dibuat.
- [ ] App membuat nama file final.
- [ ] App menyimpan/copy file final ke folder arsip.
- [ ] App menulis metadata ke spreadsheet.
- [ ] Semua proses final harus tercatat di log.

## Metadata

- [ ] Kolom metadata Laci 1 sudah sesuai.
- [ ] Kolom metadata Laci 2 sudah sesuai.
- [ ] Kolom metadata Laci 3 sudah sesuai.
- [ ] Kolom metadata Laci 4 sudah sesuai.
- [ ] Ada kolom wajib yang belum dicatat.
- [ ] Ada kolom yang boleh otomatis.
- [ ] Ada kolom yang wajib manual.

## Naming

- [ ] Pola nama file final sudah benar.
- [ ] Format nomor item sudah benar.
- [ ] Format tingkat perkembangan sudah benar.
- [ ] Format nomor surat sudah benar.
- [ ] Ringkasan perihal boleh diedit manual.
- [ ] App harus mencegah nama file duplikat.

## Write Safety

- [ ] App tidak boleh mengubah file sumber.
- [ ] App tidak boleh menghapus file.
- [ ] App tidak boleh memindahkan file sumber.
- [ ] App hanya copy file final setelah approval.
- [ ] App hanya write spreadsheet setelah approval.

## Parking Lot

Topik untuk meeting berikutnya:

- [ ] Lampiran dokumen awal/tengah/akhir.
- [ ] Perwakilan peserta.
- [ ] Template surat Word.
- [ ] Template dokumen Excel.
- [ ] Apakah lampiran cukup link di spreadsheet atau harus dicopy ke folder arsip.
